## Upstream changes that shaped this rebase

- **`layers/communicator.py` is gone** (#41438/#41439 and the layer-boundary series). Layers declare their
  stages (`declare_attn`/`declare_ffn`, `append_stages`) and every sum runs in
  `layers/layer_boundary/ops.py` (`attn_tp_all_reduce`, `sum_output`), called from `prepare.py` (the
  attention → FFN read) and `exit.py` (FFN and mixer exits). Our HIP FP32 attention-TP all-reduce (001) now
  lives in `attn_tp_all_reduce`, and the per-model opt-out that `LayerCommunicator(hip_fp32_allreduce=False)`
  carried (080/084/085) is a `ResidualUpdate` policy attribute: `PlainAdd.hip_fp32_sum = True`,
  `PLAIN_ADD_BF16_SUM.hip_fp32_sum = False`, read with `getattr(update, "hip_fp32_sum", True)` at every
  call site (both prepare paths, both exit sum sites). Laguna, Qwen3-MoE and GLM4-MoE declare
  `declare_attn(update=PLAIN_ADD_BF16_SUM)`.
- **Linear layers take a `parallel_group`** (`"tp" | "attn_tp" | "replicated" | ReplicatedParallelGroup(group,
  replica_size)`) instead of `tp_rank`/`tp_size` kwargs, and `linear_attn_parallel_group()` names the DeltaNet
  head group. 001's "DeltaNet projections replicated on every rank" is therefore
  `ReplicatedParallelGroup(linear_attn_parallel_group(), real_tp_size)` on every DeltaNet linear (conv1d,
  in_proj_qkvz, in_proj_ba, out_proj; `A_log`/`dt_bias` loaders follow the group, so that hunk is gone) with
  `output / real_tp_size` before the boundary sum (both forward paths, including the AITER fp8 one);
  the replicated MLP is `Qwen2MoeMLP(parallel_group="replicated")` with the same rescale before
  `ffn_exit.finish`. 045's `_should_replicate_deltanet_for_tp` refinement applies unchanged.
- **Block-FP8 GEMM moved** from `kernels/ops/quantization/fp8_kernel.py` to `kernels/ops/gemm/fp8_kernel.py`
  (#41243): 005's RDNA4 default config, `num_stages=0` and the torch dequant fallback are re-homed there;
  `fp8_utils` imports follow.
- **Mamba `extra_buffer` on HIP.** `arg_groups/mamba_hook._platform_supports_mamba_cache_extra_buffer` now
  includes `platform.is_hip`, so the `auto` strategy would resolve `extra_buffer` and re-enable overlap
  scheduling for every gfx1201 hybrid — including the running bake-off. 073 pins `no_buffer` on gfx1201 (the
  validated path; the state-snapshot kernels are untested here) and leaves `--mamba-radix-cache-strategy
  extra_buffer` as the explicit opt-in for a later A/B. The resolved config of the promoted server is
  byte-for-byte the v0.5.20 one (`no_buffer`, overlap disabled, `chunked_prefill_size 4096`, `mem 0.88`,
  DSPARK, graphs `bs=1`).
- **Unified radix cache on a Rust core** (#39627, `RustUnifiedTreeCore`): built with cargo on the first boot
  (`rust/sglang-radix-tree`, ~1 min, cached afterwards); `SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python`
  forces the Python core. `MambaRadixCache`/`SWARadixCache` are gone (the unified cache carries the Mamba
  component).
- **NGRAM on HIP** now routes to the tvm_ffi JIT tree kernel (#43328); 058 wraps that call with its exact
  pure-torch port as the fallback.
- **DSpark:** `SGLANG_DSPARK_FOLDED_SAMPLING` is a no-op (`SGLANG_DSPARK_USE_GREEDY_DRAFT` added, #43668/#43670);
  the worker takes the scheduler's `pp_proxy_tensors` (099 upstreamed). The split-KV verify kernel is still
  gfx95-gated upstream (100 unchanged in substance).
- **Secret redaction grew upstream** (`sampling/watermarking/core.redact_watermark_secrets`,
  `ServerArgs.__repr__` hiding watermark fields, `utils/common.build_server_info` shared by HTTP and gRPC,
  `tokenizer_manager._server_args_for_dump`, `scheduler_components/internal_state.py`). 096 composes at those
  chokepoints: `build_server_info` → `server_args_to_public_dict`, `__repr__` adds `sensitive_fields`,
  `internal_state.get_internal_state` → `redact_server_args_dict`, dump snapshot / `_server_args_for_dump` /
  `launch_command` (`redact_sensitive_cli_args` inside `redact_watermark_command_line`). Admin auth on
  `/load_lora_adapter_from_tensors` landed upstream (#41322).
- **Upstreamed and dropped:** 099 (whole patch); 055's `qwen3_vl` EAGLE3 capture dispatch (the wrapper now
  calls the backbone's `set_eagle3_layers_to_capture`, which marks `_is_layer_to_capture`); 075's
  `load_topk_ids` (model-config-driven layer counts); 098's `gemma4_unified` `lm_head_is_tied`; 096's LoRA
  admin gate.
- transformers 5.19.0 still carries `LlamaConfig.validate_architecture`'s divisibility check (055's
  `_patch_llama_head_dim_validation` stays, registered after `_patch_rope_parameters_validation`) and SGLang
  still registers `_Gemma4UnifiedConfigAlias` (098's native-config hunk stays).
- The HIP EAGLE verify "silently sampling greedy" fix (#37134) and the HIP greedy-verify TP broadcast are in
  this base; the v5 lanes run DSpark, whose draft/accept path is the one measured below.

## Series transition: 73 → 73 (099 dropped, 104 added)

**38 applied clean, 35 failed**. Sequential rebase (apply in order, `git apply --reject` the failing one,
